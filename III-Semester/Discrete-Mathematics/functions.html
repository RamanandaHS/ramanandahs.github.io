Fig. 07 — Key Ideas

Definitions

Function

Every element of the domain has exactly one image in the codomain.

Domain

The set of input values.

Codomain

The set in which the output values are specified to lie.

Range

The set of actual output values.

One-One (Injective)

Different inputs have different outputs.

Onto (Surjective)

Every element of the codomain has at least one preimage.

Bijective

A function that is both one-one and onto.
