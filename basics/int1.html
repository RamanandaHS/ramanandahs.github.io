Level 1: Basic Integration

Integration is the reverse process of differentiation. In this level, you will learn the most important basic integration formulas, see worked examples, and solve two challenges.

1

Know the Basic Rules

Power Rule
\[ \int x^n dx = \frac{x^{n+1}}{n+1}+C \]
\(n\neq -1\)
Constant
\[ \int k\,dx = kx+C \]
Exponential
\[ \int e^x dx = e^x+C \]
Reciprocal
\[ \int\frac{1}{x}dx = \ln|x|+C \]
Sine
\[ \int\sin x\,dx = -\cos x+C \]
Cosine
\[ \int\cos x\,dx = \sin x+C \]
⭐ Remember: For an indefinite integral, always remember the constant of integration + C .
2

See How It Works

Example 1 — Power Rule
\[ \int x^4\,dx \]
Step 1: Increase the power: \(4+1=5\)
Step 2: Divide by the new power, 5.
\[ \boxed{ \int x^4dx = \frac{x^5}{5}+C } \]
Example 2 — Constant
\[ \int7\,dx \]
\[ \boxed{7x+C} \]
Example 3 — Trigonometric
\[ \int\cos x\,dx \]
\[ \boxed{\sin x+C} \]
Example 4 — Exponential
\[ \int e^x\,dx \]
\[ \boxed{e^x+C} \]
Example 5 — Reciprocal Function
\[ \int\frac{1}{x}\,dx \]
\[ \boxed{\ln|x|+C} \]
