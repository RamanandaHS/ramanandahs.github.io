Field Guide

Learn the Four Types

Each type has a recognizable form. Study the clue, check the example, then reveal the reasoning.

🟢 Type 01

1️⃣ Linear Differential Equation

\( \dfrac{dy}{dx} + P(x)y = Q(x) \)
y and dy/dx appear only to the first power and are not multiplied together.
Example
\( \dfrac{dy}{dx} + 2y = x \)
P(x) = 2    Q(x) = x
✅ Linear Differential Equation
The equation matches the standard form y' + P(x)y = Q(x), with y appearing only to the first power.
🟣 Type 02

2️⃣ Bernoulli Differential Equation

\( \dfrac{dy}{dx} + P(x)y = Q(x)y^{n} \)
Looks almost like a linear equation, but contains a non-linear power of y.
Example
\( \dfrac{dy}{dx} + y = xy^{2} \)
n = 2
✅ Bernoulli Differential Equation
The equation contains y² and matches the Bernoulli form y' + P(x)y = Q(x)y^n. Substitution v = y^(1−n) converts it into a linear differential equation.
🔵 Type 03

3️⃣ Exact Differential Equation

\( M(x,y)\,dx + N(x,y)\,dy = 0 \)
Exact when \( \partial M/\partial y = \partial N/\partial x \).
Example
\( (2xy+3)\,dx + (x^{2}+4y)\,dy = 0 \)
M = 2xy + 3    N = x² + 4y
∂M/∂y = ?
⇄
∂N/∂x = ?
✅ MATCH! → EXACT
🟠 Type 04

4️⃣ Reducible to Exact Differential Equation

Not exact at first — but multiplying by a suitable integrating factor μ makes it exact.
Example
\( y\,dx + (2x - y)\,dy = 0 \)
∂M/∂y = 1  ≠  ∂N/∂x = 2  → Not Exact
↓ multiply by μ(y) = y
∂(μM)/∂y = 2y = ∂(μN)/∂x = 2y  → Exact
✅ Reducible to Exact
Method

🔍 How Do I Identify the Type?

Answer each question below and follow the trail.

Can it be written as \( y' + P(x)y = Q(x) \)?
Does it have the form \( y' + P(x)y = Q(x)y^{n} \)?
Can it be written as \( M\,dx + N\,dy = 0 \)?
Check: \( \partial M/\partial y = \partial N/\partial x \)?
Can an integrating factor make it exact?
